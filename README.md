Персональное демо на базе шаблона Mirelle. Дизайн, анимации и спокойные ховеры шаблона сохранены, заменены бренд, данные, услуги и фото.
Сборка не нужна: открыть `index.html` или залить папку на Vercel.

## Скрыто / убрано
- **До / После** — в источниках нет парных снимков бровей. Пары есть только по косметологии в Telegram, но они маленькие (≈290 px) — на сайте были бы мыльными. Блок скрыт.
- **Команда** — имена мастеров есть только в постах ВК 2022 года, актуальность не подтверждена. Блок и пункт меню скрыты.
- **Отзывы** — выдуманные отзывы шаблона убраны, блок скрыт.
- Цифры, мастера и реквизиты шаблона убраны. Цифры на сайте — только подтверждённые (рейтинг 5,0 в 2ГИС, 4 направления, 7 дней, 9:00–21:00).

## Согласовать со студией перед публикацией
1. **Все фото** — из ВК и 2ГИС студии, часть публиковали сами мастера (2022). Нужно разрешение.
   На фото маникюра с пером есть подпись `@top.nail.krd` — уточнить, что это аккаунт мастера студии.
2. **Цены** — вилки из ВК опубликованы в 2022 году, проверить актуальность. Добавить цены для услуг «по записи», если студия их даст.
3. **Косметология** — список процедур взят из Telegram-канала косметолога (2023–2024): уточнить, что всё актуально.
4. **Мастера** — если студия подтвердит состав и даст фото, блок команды включается в `config.js` (`team`).
5. **Рейтинг 5,0** — данные 2ГИС на 10.11.2026 (6 оценок).
